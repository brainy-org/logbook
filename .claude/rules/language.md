# Language

Everything written in this repository uses one language: English.
It covers UI strings, URL segments, identifiers, code comments, documentation,
decision records, log lines, prompts sent to models and commit messages.

- This rule is about new writing too: an existing file in another language is
  not evidence of the house style, this rule is. If you find text in another
  language where you are working, translate it as part of the task.
- Data is not prose: values that must stay in another language (e.g. a list of
  words checked at runtime) stay as they are, with a comment saying why.
- The rule is about what is written in the repository, not about the
  conversation: always answer the person in the language they write in.
