Where is it? The server made it at its first start, in admin.token in its data folder, and says where in its log when it starts:

On macOS ~/Library/Application Support/logbook-server/admin.tokenon Linux ~/.local/share/logbook-server/admin.tokenor in the folder given as --data.

A server started with --admin-token (LOGBOOK_ADMIN_TOKEN) takes that one instead.
